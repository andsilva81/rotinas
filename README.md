- **HTML + CSS + JavaScript puro**, tudo em um único arquivo por calculadora.
- Sem frameworks, sem instalação, sem passo de build.
- Responsivo e com suporte a **tema claro/escuro** automático.

Compara Simples Nacional × Lucro Presumido, calcula pró-labore (INSS + IRPF) e retenções na fonte de venda para órgão público. | [▶️](calculadora-impostos-saas.html) |

> ⚠️ **Aviso:** as ferramentas deste repositório são estimativas para planejamento e estudo. **Não** substituem aconselhamento contábil, jurídico ou financeiro. Confirme sempre os números com um profissional antes de recolher tributos ou tomar decisões.
> Os valores usados (salário mínimo, teto do INSS, faixas do Simples, tabela do IRPF) são referentes a **2026** e devem ser revisados a cada ano.
